01 · Pipeline

六阶段周度流水线

收集、验证、合成、仲裁、决策、发布——每阶段有显式交接契约，产物全程可审计。

STAGE 01

收集

行情、公告、新闻、宏观、商品的带日期观察，统一交付校验层。

STAGE 02

验证

信源一致性、时间戳、缺失与冲突检查；未解决分歧阻断结论。

STAGE 03

合成

六视角打分经 MCDA（TOPSIS + VIKOR）硬合成为中立证据矩阵。

STAGE 04

仲裁

硬生存门槛 + 信号优先级；规则引擎主裁，哲学灰区兜底。

STAGE 05

决策

把红绿灯翻译为下周条件化检查点、触发区间与风控。

STAGE 06

发布

渲染可审计的 Markdown / HTML 周报，含证据截止点。

单一问责中枢 —— 任何产物必须经过 进化负责人（中枢） 中转，禁止越级直连。

03 · Discipline

信号分层：顺序即纪律

宏观叙事不能推翻有效的布林带证据；布林带结果也不能推翻数据冲突、小样本回测或生存风险门槛。

数据完整性
未解决的价格分歧阻断方向性结论。
历史 BOLL
权重最高的技术输入，但不是保证——须先过数据质量与生存风险门槛。
量价与资金确认
单日波动抹不掉中期信号；5/10/20 日资金流须与量价一致。
公司证据
带日期的披露才能改变论点；后发事件永不回填先前报告。
宏观背景
已核验的宏观因子只调整风险预算——约束风险，不制造交易。
