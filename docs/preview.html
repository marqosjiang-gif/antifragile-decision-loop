01 · Pipeline

六阶段周度流水线

收集、验证、合成、仲裁、决策、发布——每阶段有显式的输入→输出契约，产物全程可审计。

STAGE 01

收集

行情、披露、新闻、宏观、商品的带日期观察，统一交付校验层。

in: 任务简报 → out: 带信源标签的原始观察
STAGE 02

验证

信源一致性、时间戳、缺失与冲突检查；未解决分歧阻断结论。

in: 原始观察 → out: 事实表 + 缺失标记
STAGE 03

合成

六视角打分经 MCDA（TOPSIS + VIKOR）硬合成为中立证据矩阵。

in: 事实表 → out: 中立证据矩阵 + 冲突清单
STAGE 04

仲裁

硬生存门槛 + 信号优先级；规则引擎主裁，哲学灰区兜底。

in: 证据矩阵 → out: 🟢🟡🔴 方向建议包
STAGE 05

决策

把红绿灯翻译为下一周期条件化检查点、触发区间与风控。

in: 建议包 → out: 条件化决策记录
STAGE 06

发布

渲染可审计的 Markdown / HTML 周报，含证据截止点。

in: 决策记录 → out: 自包含周报

单一问责中枢 —— 任何产物必须经过 进化负责人（中枢） 中转，禁止越级直连。

02 · Expert Council

八角色 subagent 规格卡

一个阶段一个责任人。复盘与进化回流后，进入下一轮收集。

沈迭代
Evolution Lead · 中枢
统一调度、阶段门禁、规则固化与自进化
owns: 调度权 + 晋级权
rejects: 越级直连
甄采集
① Info Collector
行情/披露/新闻/宏观/地缘/商品一键采集
in: 简报 → out: 原始观察
fails: 标注缺失，不编造
严求真
② Info Verifier
168h+120h 窗口交叉验证，输出事实表
in: 观察 → out: 事实表
rule: 双信源或标疑
程多维
③ Synthesizer
六视角 MCDA 硬合成中立证据矩阵
in: 事实表 → out: 证据矩阵
stance: 中立，不下结论
仲衡
④ Arbitrator
规则引擎主裁决 + 反脆弱哲学灰区兜底
in: 矩阵 → out: 🟢🟡🔴
rule: 硬门槛不可旁路
决断行
⑤ Decision Maker
红绿灯 → 触发区间 / 敞口增减 / 风控
in: 红绿灯 → out: 条件化决策
rule: 只条件化，不预测
圆汇众
⑥ Research Editor
Markdown → 自包含 HTML 周报
in: 决策记录 → out: HTML 周报
rule: 不改结论只排版
顾镜
⑦ Review Expert
上周决策 vs 实际走势，结构化复盘
in: 报告+实际 → out: 复盘记录
rule: 截止点前信息 only
03 · Discipline

信号分层：顺序即纪律

宏观叙事不能推翻有效的趋势通道证据；通道结果也不能推翻数据冲突、小样本验证或生存风险门槛。每层只对自己的问题负责。

数据完整性
未解决的信源分歧阻断方向性结论。
responsible: 验证层
历史趋势通道
权重最高的背景证据，但不是保证——须先过数据质量与生存风险门槛，且样本充足。
responsible: 合成层
核心指标与资金确认
单日波动抹不掉中期信号；5/10/20 日资金流转须与核心指标一致。
responsible: 合成层
披露证据
带日期的披露才能改变论点；后发事件永不回填先前报告。
responsible: 仲裁层
宏观背景
已核验的宏观因子只调整风险预算——约束风险，不制造结论。
responsible: 仲裁层
W1 · 生成周报脚手架 + 证据截止点
W2 · 复盘判断 vs 实际，识别复现缺口
W2.5 · 人工/政策门规则/阈值/角色/数据源变更必须过门
W3 · 进化测试 + 晋级，保留回滚路径

门语：能改进流程的，先过人这一关——批准、留痕、可回滚，缺一不晋级。
